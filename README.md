# CrossPascal homepage

[Open the interactive homepage](https://pisarev.github.io/crosspascal-live/).

The homepage covers CrossPascal EA023 for Windows x64, including OmDet-Turbo text-guided detection, BiRefNet background removal, PaddleOCR, and language and vision examples. Source repositories and release downloads are public.

Green labels identify downloadable examples. Grey labels identify pending examples or planned work. Illustrations and recorded outputs are labelled on the page.

The examples run locally in Delphi and Lazarus. This repository serves the static homepage.

The bus photo is the pinned Ultralytics sample linked from the page. The Gemma image response is recorded output from the EA015 Lazarus ImagePrompt example.

BiRefNet previews use the actual HR800 CUDA output on the NASA public-domain photograph of Eileen Collins. The model packages include the pinned upstream MIT declaration and notices.

OmDet-Turbo previews use the annotated PNG saved by the Pascal example from the same NASA photograph. CUDA preparation selects compiled bundles for compute capabilities 7.5, 8.6, 8.9, and 12.0.

EA023 adds text and image input for Huihui Gemma 3n E4B abliterated and Qwen3.8-27B, with dedicated CPU/CUDA preparation kits.
