Prepare. Open. Run.

Start with Qwen2.5-VL 3B or Gemma 3n E4B. Each preparation script downloads the SDK, runtime, model and a sample image, then sets the project paths for you.

  1. 01Download a preparation ZIP below, extract it, and run Prepare.cmd.
  2. 02Wait for READY. In the folder it opens, open the .dproj in Delphi 13.2 or the .lpi in Lazarus 4.8.
  3. 03Select Windows 64-bit and Run. In the chat, select Load model, then Generate.
Prepare QwenChatPrepare GemmaChat
First run: access, storage and IDE steps
  1. Use a GitHub account with access to pisarev/crosspascal. Prepare uses an existing GitHub CLI login or asks for a token with Contents: Read-only access to that repository. Input is hidden; saving it in Windows Credential Manager is optional.
  2. Keep the extracted preparation files together. Prepare downloads a portable runtime; you do not need to install Python, copy DLLs or convert a model. It verifies checksums and resumes interrupted package downloads.
  3. Qwen-VL needs about 24 GiB RAM and a 5.2 GiB model download; Gemma 3n needs about 32 GiB RAM and an 11.4 GiB model download. These two CPU bundles require AVX2 and FMA (Haswell-compatible or newer). Allow room for the extracted models and runtime. Prepare checks free disk space first.
  4. The default install is %LOCALAPPDATA%/CrossPascal/early-access-016. To use another drive, set CROSSPASCAL_PREPARE_HOME before starting. Models and cached downloads are shared between examples.
  5. Open the prepared project, select Release and Windows 64-bit, then Run. The model, SDK and sample-image paths are already filled in. In either chat, select Load model and Generate; Stop requests cancellation and Unload releases the model.

Read the complete preparation guide for all 13 projects, model terms, storage and troubleshooting.

The scripts share downloaded files, preserve edits to SDK sources and keep your existing settings. CPU image requests can take minutes. All supplied Pascal executables are built with Lazarus.

Six small Pascal examples.

Each name downloads its preparation script. Extract the ZIP, run Prepare.cmd, then open the prepared project and Run. These console examples use the same API as QwenChat and GemmaChat.

  1. 01LoadUnload. Inspect, load and unload a model.
  2. 02GenerateText. Submit a prompt and receive the answer.
  3. 03GenerationSettings. Set the supported generation parameters.
  4. 04StreamAndStop. Read text as it arrives and stop generation.
  5. 05RepeatedRequests. Reuse loaded weights across independent requests.
  6. 06ImagePrompt. Ask about an image with a compatible model.

All generation examples accept an image when the selected bundle supports it. LoadUnload demonstrates lifecycle only.

Explore the five projects

Start with the matched SDK. It groups the five projects from the same release. You can also use the library bindings in your own Pascal applications.

  • CrossPascal

    Examples and shared Pascal code.

  • Converter

    Build a model bundle for a supported CPU or CUDA target.

  • Apache TVM 0.26.0

    Run compiled models from Delphi or Lazarus. The Pascal runtime bindings use TVM FFI 0.1.14 and support module loading, tensor exchange through DLPack, and function calls.

  • OpenCV 4.10.0 + contrib

    Use OpenCV in your own Pascal applications through CrossCV. The bindings name 1,336 bridge entry points across image processing, video, and other modules. IMat provides higher-level image operations.

  • Leptonica 1.87.0

    Use Leptonica directly from Pascal for image analysis and document processing. The bindings name all 2,743 functions declared in the bundled allheaders.h. IPix provides higher-level image operations.

Versions match this release. The counts describe binding names. Runtime validation covers the scenarios listed in each project’s documentation.
