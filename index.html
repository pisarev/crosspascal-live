Run a model on CPU.

  1. 01Download the model bundle.
  2. 02Add the runtime libraries.
  3. 03Run the example.

CPU preview · Gemma 2 2B has run on CPU with an experimental TVM profile.

GPU · NVIDIA CUDA · Conversion required

Or run it on your GPU.

Prepare a bundle for your graphics card with CrossPascal Converter. Python is used during conversion.

  1. 01Open CrossPascalConvert.exe and choose a supported Qwen model.
  2. 02Keep the detected CUDA architecture, or select the target for another computer.
  3. 03Review the settings in Preview, then select Build.
  4. 04Open the exported bundle in QwenChat and run a prompt.

Planned · Qwen and Gemma

Five small Pascal examples.

Copy the pieces you need into your own app. Each example focuses on one task and runs without a visual interface.

  1. 01Load a model. Open a CPU bundle in system RAM or load a GPU bundle for the selected device.
  2. 02Set generation options. Set the output token limit and, where the profile supports sampling, adjust temperature, top-k, top-p, repetition penalty, and random seed.
  3. 03Attach an image. Add images to a text prompt with a compatible vision model and runtime.
  4. 04Run inference. Read the full answer or stream it as it arrives.
  5. 05Unload the model. Close the session and release its memory.

Explore the five projects

Start with the matched SDK. It groups the five projects from the same release. You can also use the library bindings in your own Pascal applications.

  • CrossPascal · Examples and shared Pascal code.
  • Converter · Build a model bundle for a supported CPU or CUDA target.
  • Apache TVM 0.26.0 · Run compiled models from Delphi or Lazarus. The Pascal runtime bindings use TVM FFI 0.1.14 and support module loading, tensor exchange through DLPack, and function calls.
  • OpenCV 4.10.0 + contrib · Use OpenCV in your own Pascal applications through CrossCV. The bindings name 1,336 bridge entry points across image processing, video, and other modules. IMat provides higher-level image operations.
  • Leptonica 1.87.0 · Use Leptonica directly from Pascal for image analysis and document processing. The bindings name all 2,743 functions declared in the bundled allheaders.h. IPix provides higher-level image operations.

Versions match this release. The counts describe binding names. Runtime validation covers the scenarios listed in each project’s documentation.

Check compatibility, validation, and the roadmap

This release was tested on Windows x64 with Delphi 13.2 and Lazarus 4.8. This release uses Windows DLLs. Linux shared libraries (.so) are outside its verification matrix. Separate engineering runs, including PaddleOCR, have their own scope.
