First run: access, storage and IDE steps
  1. The repositories and releases are public. Prepare downloads without a GitHub account or token. If GitHub limits anonymous requests, you can retry with an optional GitHub CLI login or token. Token input is hidden; saving it in Windows Credential Manager is optional.
  2. Keep the extracted preparation files together. Prepare downloads a portable runtime; you do not need to install Python, copy DLLs or convert a model. It verifies checksums and resumes interrupted package downloads.
  3. On CPU, Qwen-VL needs about 24 GiB RAM and a 5.2 GiB model download; Gemma 3n needs about 32 GiB RAM and an 11.4 GiB model download. These two CPU bundles require AVX2 and FMA (Haswell-compatible or newer). Plan for 45 GiB of free disk space for Gemma 3n, including the download and extracted files. Prepare checks free disk space first.
  4. The default install is %LOCALAPPDATA%/CrossPascal/early-access-020-r5. To use another drive, set CROSSPASCAL_PREPARE_HOME before starting. Models and cached downloads are shared between examples.
  5. Open the prepared project, select Release and Windows 64-bit, then Run. The model, SDK and sample-image paths are already filled in. In either chat, select Load model and Generate; Stop requests cancellation and Unload releases the model.

Read the complete preparation guide for all 14 projects, model terms, storage and troubleshooting.

The scripts share downloaded files, preserve edits to SDK sources and keep your existing settings. CPU image requests can take minutes. All supplied Pascal executables are built with Lazarus.

Dependency details & website repositories

Choose a route

OpenCV and Leptonica can each be used without TVM, the converter, or an AI model. The TVM interface can be reused without the CrossPascal demo applications; its current Pascal unit also needs OpenCV type declarations.

The converter and Pascal consumers use the same pinned Apache TVM / TVM FFI runtime. A ready model bundle lets you skip conversion. Pure Pascal geometry and set algorithms need none of these native runtimes.

Library APIs and ready-to-run examples

Start with the matched SDK. It groups the five projects from the same release. You can also use the library bindings in your own Pascal applications.

  • CrossPascal

    Examples and shared Pascal code.

  • Converter

    Build a model bundle for a supported CPU or CUDA target.

  • Apache TVM 0.26.0

    Run compiled models from Delphi or Lazarus. The Pascal runtime bindings use TVM FFI 0.1.14 and support module loading, tensor exchange through DLPack, and function calls.

  • OpenCV 4.10.0 + contrib

    Use OpenCV in your own Pascal applications through CrossCV. The bindings name 1,336 bridge entry points across image processing, video, and other modules. IMat provides higher-level image operations.

  • Leptonica 1.87.0

    Use Leptonica directly from Pascal for image analysis and document processing. The bindings name all 2,743 functions declared in the bundled allheaders.h. IPix provides higher-level image operations.

Preparation, downloads and first-run help

Prepare.cmd downloads the SDK, native libraries and a compatible CPU or CUDA bundle for the selected example. It verifies the files and sets the project paths.

The combined ZIP uses Auto by default. Run Prepare.cmd -All -Device CPU for all examples on CPU or Prepare.cmd -All -Device CUDA to require CUDA for the examples that offer it.

Downloads are verified and shared across examples. Interrupted package downloads can resume. With an empty cache, all 14 examples need about 21.2 GiB in CPU mode or 16.3 GiB on CUDA (sm_89), plus space for extracted files. You can prepare just one example. Check model and library licenses before use.

CUDA requirements. Prepare ships bundles for compute capability 6.1, 7.5, 8.6, 8.9 and 12.0. The driver must support CUDA 12.8. An RTX 4060 Ti ran the language and vision examples. A GTX 1650 ran all five vision profiles. The remaining targets were checked at build time. See the GPU table, VRAM requirements and test results. Prepare prints its memory check before downloading the model. Use Prepare.cmd -Device CPU to choose CPU.

The dense Qwen2.5 0.5B/1.5B and Coder 0.5B checkpoints shown here use Apache-2.0. Check the exact checkpoint; licenses differ across the family.

The Gemma Terms of Use and Prohibited Use Policy apply to these models and derivatives. Bundles include the terms, NOTICE, modification records and redistribution guidance.
